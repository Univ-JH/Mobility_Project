# Infra (인프라 매니지먼트)

전체 Safe Mobility System 프로젝트의 시스템 컨테이너들을 띄우고, 클라우드 환경에 어떻게 배포하고 운영(Provisioning/Deployment) 하는지 문서화 및 자동 스크립트화가 위치한 도메인입니다.

## 핵심 자료 구성
- **[Docker Compose](./docker-compose.yml) 기반 MVP 배포판**: 로컬 및 초기 개발 테스트용 컨테이너(FastAPI 기반 백엔드, MQTT 브로커, MongoDB 데이터베이스) 통합 구성 파일
- **클라우드(AWS) 아키텍처 배포 팁**: 추후 프로덕션 환경 도달 시 ECS 기반 워커, 로드밸런싱 설정 및 보안 가이드라인 스크립트 작성처
- **네트워크 보안 및 인증 설정**: 통신에 필요한 TLS/SSL 사설(혹은 서티드) 인증서 발급 규칙, 방화벽(Security Group) 허용 포트 나열 가이드

## 존재 의의
팀원들의 "내 컴퓨터(환경)에선 잘 돌아갔는데?" 라는 문제를 컨테이너 가상화를 통해 완전히 없애고 동일하게 배포 단절을 극복하기 위해 설계되었습니다. 로컬에서 환경을 재현하려면 단독으로 이 폴더의 명세서를 통해 스핀업(Spin-up) 할 수 있어야 합니다.
