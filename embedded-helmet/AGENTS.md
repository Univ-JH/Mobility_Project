# Embedded-Helmet 폴더 전용 AI 개발 규칙

Arduino C++ (Nano 33 BLE 환경) 기반의 임베디드 코드를 작성, 수정 시 따라야할 철칙입니다.

## 핵심 규칙
1. **메모리 절약 최적화 (No Heap)**: 마이크로컨트롤러 환경 특성상 메모리 누수와 단편화에 매우 취약합니다. 힙 메모리 동적 할당(`new`, `malloc`, `String 객체 남용` 등)을 철저히 금하고 C 스타일의 정적 스택(Stack) 배열과 포인터를 활용하세요.
2. **논블로킹 제어 루프 (Non-blocking)**: 펌웨어에서 `delay()` 구문은 프로세스를 완전히 세워버립니다. 밀리초 시계인 `millis()`를 이용하여 현재 시각 대비 만료시간 기반으로 동작하는 '비동기 State Machine 루프 패턴'을 뼈대로 삼아야 합니다.
3. **노이즈 필터링 보수성**: 아날로그 센서 데이터는 항상 노이즈(전기적 요동)를 품고 있습니다. 순간적인 값 튀어오름에 오작동하지 않게 항상 LPF(Low Pass Filter), 이동 평균선 혹은 히스테리시스 버퍼를 거친 후에만 이벤트를 방출하도록 설계하세요.
4. **엄격한 BLE 통신 계약**: BLE 통신의 Telemetry 주기 및 패킷 전송 구조는 `PROJECT_MASTER_PLAN.md`에 정의된 GATT 프로토콜 가이드라인을 어겨서는 안 됩니다. 
5. **Cursor Rules**: 상세한 추가 준칙은 `.cursor/rules/50-embedded-arduino-ble.mdc`를 참고합니다.
