# Docs (도큐먼트 아카이브)

프로젝트를 조망하는 마스터 설계도(`PROJECT_MASTER_PLAN.md`)에서 풀어내지 못한 데이터 파라미터나 실무 도메인 지식, 정책 명세서 등이 모여있는 백과사전 공간입니다.

## 내부 카테고리 구성
- `specs/`: MQTT 토픽과 페이로드 디테일, API 엔드포인트 URL 구조 등 실무와 맞닿은 "계약서" 명세
- `data-dictionary/`: 데이터베이스 컬렉션과 시스템 내 상태 변수명, 제어로직명들의 일관된 정의(Data Dictionary) 나열서
- `runbooks/`: 서버가 죽었을때 파악하는 요령, 특정 장애 시나리오 시 복구 스텝을 나열한 트러블슈팅(Troubleshooting) 시나리오

## 존재 의의
개발자(알고리즘)와 AI 에이전트 모두가 길을 잃거나 각기 다른 스키마 변수명(예: 누군가는 `pressure_sum`, 누군가는 `allPressure`)을 통일되게 참조할 수 있도록 만들어진 "단일 진실 공급원(Single Source of Truth)" 역할을 수행합니다.
