# edge-pi/src/control

서보 모터와 초음파 센서를 이용한 하드웨어 제어 및 실시간 거리 측정 로직을 담당한다.

## 호환성
- **정책 기반 제어**: `SafetyStateMachine`에서 결정된 제동 레벨 명령을 즉각적으로 물리적 동작으로 변환한다.
- **Fail-Safe 연동**: 센서 데이터가 불확실하거나 단절될 경우, 즉시 가장 보수적인 제동 상태로 전이하여 주행 안전을 확보한다.

## 확장성
- **데이터 기반 캘리브레이션**: 제동 각도, PWM 펄스 폭 등 모터 특성 수치를 코드에 하드코딩하지 않고 `servo_calibration.json` 또는 `control_config.py`에서 동적으로 로드한다.
- **교체 용이성**: 인터페이스가 규격화되어 있어, 다른 기종의 서보 모터나 거리 측정 센서로 교체 시 설정 파일 수정만으로 대응이 가능하다.

## 가시성/명확성
- **구조화된 로깅**: 모든 제동 이벤트 발생 시 `rideId`, `reason`, `severity`, `brakeLevel` 필드를 포함한 JSON 로그를 생성하여 관측성을 유지한다.
- **명확한 명령 근거**: 제어 명령 실행 시 해당 동작이 발생한 원인(장애물 감지, 센서 신뢰도 저하 등)을 로그에 명시하여 사후 분석을 용이하게 한다.

## 📂 파일 구성
1. `control_config.py`: 핀 번호(BCM), 센서 임계치, 음속 상수, 제동 레벨별 각도 등 하드웨어 상수 관리
2. `servo_control.py`: `pigpio` 데몬을 활용한 하드웨어 PWM 기반 서보 모터 정밀 제어 및 제동 실행
3. `ultrasonic.py`: HC-SR04 센서를 이용한 거리 측정 및 타임아웃/노이즈 필터링 등 예외 처리 클래스
4. `servo_calibration.json`: 서보 모터의 물리적 구동 범위 보정 및 펄스 매핑 테이블

## 🚨 제어 우선순위
1. **CRITICAL**: 헬멧 미착용 또는 사고/전도 감지 (**EMERGENCY** 제동)
2. **HIGH**: 전방 장애물 근접 또는 센서/비전 데이터 불확실 (**LEVEL_2** 강한 제동)
3. **MEDIUM**: 인도 주행 판별 (**LEVEL_1** 감속 제동)
4. **LOW**: 정상 주행 환경 확인 (**LEVEL_0** 제동 해제)
