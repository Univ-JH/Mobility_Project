# Edge-Pi 폴더 전용 AI 개발 규칙

이곳의 주 처리 코드는 Raspberry Pi 5(Edge 환경)의 Python 스크립트로 동작합니다. 코드 생성 시 하드웨어의 특수환경에 적합한 다음 룰셋을 준수하세요.

## 핵심 규칙
1. **안전 제일! Fail-Safe 제어 원칙**: 만약에 카메라에 먼지가 묻거나 야간이라 인식률이 떨어지는 등 "Uncertain(불확실한 상태)" 상태일 시, 정책 중 **가장 방어적 수단(속도 제한 또는 감속 정지)**으로 자동 전이시키는 폴백 방어가 필수입니다. "보이지 않으면 멈춘다"는 대명제를 따르세요.
2. **실시간성(Low Latency) 절대 고수**: OpenCV 비전 작업이나 AI 추론 때문에 다른 주요 수집이 방해받으면 안 됩니다. `collections.deque` 등을 사용하여 스레드 큐 관리를 해주거나 메인 스레드 블로킹 현상을 철저히 배제하세요.
3. **오프라인 / 단절 대응망**: 서버(MQTT Broker)나 헬멧(BLE) 연결이 잠깐 단절되는 일은 빈번합니다. 접속 장애 감지 시 엣지에 마련된 버퍼에 이벤트를 적재하고, "FAULT 전이" 로그를 발산한 뒤 재연결 시 쏟아부어야 합니다. 재연결(Backoff) 로직 구현이 핵심입니다.
4. **하드웨어 캘리브레이션 분리**: `control` 디렉터리의 서보모터 구동 제어각, 스텝 제한수 같은 H/W 수량 변수를 Python 스크립트(.py) 안에 절대 하드코딩(마커)하지 마세요. `servo_calibration.json` 등 참조 테이블 형태로 빼서 읽어오도록 제작해야 합니다.
5. **Cursor Rules**: `.cursor/rules/40-edge-raspberrypi.mdc`를 참조하세요.
