# Edge-Pi (Raspberry Pi Edge Device)

주행 이동장치(킥보드, 자전거) 본체에 중심제로 장착되어 메인 "주행 통제 기관" 역할을 수행하는 환경입니다. 복잡한 지연 없이 즉각적으로 상황을 처리하기 위해 클라우드가 아닌 Edge 기법을 이용합니다.

## 기술 스택
- **사용 보드**: Raspberry Pi 5
- **사용 언어**: Python 3.10+
- **동작 엔진**: 경량 딥러닝 비전 AI 모델 구동 (MobileNet 분류 기반 혹은 Hailo-8 NPU 최적화)
- **통신 / 제어**: MQTT (서버 수발신), BLE (헬멧에서 오는 센서 수신), PWM 기반 브레이크용 Servo Control

## 내부 폴더 명세
- `src/ai/`: 하향 카메라에 잡힌 이미지를 통해 노면 공간(인도, 차도 등)을 판별해내는 AI 추론 엔진 및 래퍼 클래스
- `src/camera/`: 영상을 30fps 로 가져오고 해상도 및 대비를 프레임 단위로 리사이징/전처리하는 파이프라인
- `src/control/`: 서보 모터를 구동하여 이동장치의 브레이크 레버를 물리적으로 쥐어잡아 감속시키는 제어 계통
- `src/state/`: 센서/카메라로부터 입력된 값들을 취합하여 안전 상태 기계(State Machine)를 로컬에서 구동하는 로직부
- `src/communication/`: 헬멧의 아두이노 장치와 맺는 BLE GATT 수신부 및 서버 클라우드로 현황을 날려보내는 MQTT 브릿지

## 역할 및 핵심 미션
카메라가 잡아낸 노면의 '인도' 주행 위험 환경, 그리고 헬멧 디바이스가 보내는 사용자의 미착용 및 추돌 사고(충격 감지) 알림을 로컬 엣지단에서 종합 분석합니다.
해당 정보가 기준 임계치를 초과하면 서버의 응답을 기다리지 않고 로컬에서 물리적 서보 브레이크를 동작시켜 기계를 안전 상태로 변환합니다.
